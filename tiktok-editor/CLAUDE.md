# tiktok-editor

Video editing toolkit for the user's TikTok/Reels clips. Before any video work:

1. Run `bash setup.sh` (installs HyperFrames skills, headless Chrome, Whisper models, fonts, GSAP).
2. Read `PLAYBOOK.md` — the user's preferences, the editing rules that work, and the technical
   pitfalls of this cloud environment. Follow it, and update it at the end of each project.

Talk to the user in simple Hebrew, without code. Keep media, transcripts and private details out of
this repo: it is public. Work files go in the session scratchpad.
